Emoji graphics for the PDF export (src/PdfExport.php)

The files in this folder are a selection of 200 commonly used emoji from
Twemoji, version 15.1.0 (https://github.com/jdecked/twemoji).

Graphics: Copyright 2020 Twitter, Inc and other contributors,
licensed under CC-BY 4.0 (https://creativecommons.org/licenses/by/4.0/).
Original source files were not modified.

File names are the lower-case Unicode code points (without variation
selectors), e.g. 1f4aa.svg for the flexed biceps. Emoji that are not in this
folder are left out of the PDF.
